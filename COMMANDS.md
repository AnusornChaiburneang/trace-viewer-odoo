# Trace Kit commands

Generated from `commands.json`. Do not edit this file directly.

- `login <user> <pass>` — log in — auto-skips if the saved session is still valid
- `goto <url>` — navigate
- `mode human|quick` — nav style for navmenu (human=click through, quick=jump via @id)
- `navmenu A > B > C [@id] | navmenu @module.xmlid` — navigate by clicking menu labels (human) or #action=id (quick); @xmlid reads the labels in the user's language
- `click <sel>` — standard Playwright click (waits for visibility)
- `fclick <sel>` — force click (bypasses visibility checks)
- `jclick <sel>` — JS .click() (OWL2-friendly for Odoo SPA buttons)
- `clickbtn <text>` — click button by visible label (prints internal name)
- `clickrpc <text>` — like clickbtn but FAILS unless a call_button/call_kw RPC fires
- `buttons` — list visible buttons: internal name + label
- `field <name> <value>` — edit an Odoo field in the active dialog/form and verify it
- `rowset <table> <row> <column> <value>` — edit an existing row (#1 or field=exact text)
- `fill <sel> <text>` — fill input (use single quotes for selectors with spaces)
- `date <sel> <value>` — set a date/datetime field WITHOUT clicking (no 30s picker hang); ISO 2026-06-01[ 18:00] is converted to the user's format
- `type <text>` — type text into focused element (keyboard events, no selector)
- `m2o <cell_sel> <text>` — many2one: click cell → clear → type → pick the MATCHING result
- `pick <text>` — pick an OPEN autocomplete option by text (skips Create/Search More; OWL+v14)
- `celltype <cell> <text>` — v14 editable-list: JS-click cell → focus its input → type
- `boolcell <cell> [on|off]` — editable-list checkbox: activate row, toggle, verify it flipped
- `scroll <sel>` — scrollIntoView, no click/focus (Odoo scrolls inside .o_content)
- `record <model> <id>` — open a record form directly by model + id (no menu needed)
- `breadcrumb [n]` — click a breadcrumb by index (default: parent level)
- `cols [table_sel]` — print a table's header cells with column index (order varies per table)
- `addline <field_name>` — add row to One2many list, waits for new row to appear
- `press <key>` — keyboard press (Enter, Tab, Escape, ArrowDown...)
- `wait <ms>` — pause (fixed — prefer waitidle/waitfor)
- `waitidle [maxMs]` — wait until Odoo is idle (network + loading overlay), fast
- `timeout <ms>` — set per-action fail-fast timeout (default 8000)
- `strict on|off` — abort the whole flow on first error/timeout (default off)
- `screenshot [name] [full|viewport]` — save screenshot to traces/ (default full page)
- `step '<title>' ['<description>']` — start a user-manual section; when the next step starts or the flow ends, a 1440x900 screenshot is saved and marks are cleared
- `capture <name> field <f> | url id | text <sel>` — record a value (e.g. document number, record id) for {{name}} and result.json
- `lang <code>` — switch the logged-in user's UI language (e.g. th_TH) and reload; the previous language is recorded in result.json
- `snapshot` — print page element tree (for selector discovery)
- `eval <js>` — evaluate a JS EXPRESSION and print the result. It is wrapped in a plain function, so top-level await is a syntax error — write `eval odoo.__WOWL_DEBUG__.root.actionService.doAction(...)` (a returned promise is awaited for you) or an async IIFE, not `eval await ...`
- `cookie <n> <v> [domain]` — set a raw browser cookie (works for HttpOnly, e.g. session_id)
- `highlight <sel>` — draw Playwright's native pink box (screenshot-only, invisible in trace viewer)
- `mark <sel> [caption]` — inject a REAL red box+caption around an element (visible in trace viewer Snapshot tab)
- `unmark` — remove all marks added by `mark`
- `bbox <sel>` — print an element's {x,y,width,height} viewport box (for custom annotation)
- `evals <sel>` — print outerHTML of matched elements (structure inspection)
- `find <sel>` — print matching elements (max 5)
- `waitfor <sel>` — wait for selector to appear
- `url` — print current URL
- `title` — print page title
- `expect <visible|hidden|text|value|state|dialog> <selector/value> [expected]` — assert a UI outcome; `expect state` accepts the label or the internal key (e.g. sale)
- `done` — stop trace, save zip, exit
