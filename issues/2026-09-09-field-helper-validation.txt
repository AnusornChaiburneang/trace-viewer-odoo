## STATUS 2026-09-20 — eval contract documented

The `eval` expression contract is now in the command registry (commands.json),
so it appears in the in-REPL help and the generated reference:

  eval <js>  evaluate a JS EXPRESSION and print the result. It is wrapped in a
  plain function, so top-level await is a syntax error — write
  `eval odoo.__WOWL_DEBUG__.root.actionService.doAction(...)` (a returned promise
  is awaited for you) or an async IIFE, not `eval await ...`

The other two items are environment/authoring guidance rather than kit bugs and
are left as recorded: pin the active DB and use its matching saved login rather
than inferring authentication from the visible page; and open an empty
account.move form before adding a line, so the parent currency/journal defaults
exist before any row helper runs.
